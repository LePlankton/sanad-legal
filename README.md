# Pages légales — Sanad

Politique de confidentialité et page de demande de suppression de compte de
l'application Android **Sanad**, publiées via GitHub Pages.

- [Politique de confidentialité](https://leplankton.github.io/sanad-legal/)
- [Demande de suppression de compte](https://leplankton.github.io/sanad-legal/suppression-compte.html)

Ce dépôt est public uniquement parce que Google Play exige que ces deux URLs
soient atteignables sans authentification. Le code source de l'application est
hébergé séparément, en privé.
